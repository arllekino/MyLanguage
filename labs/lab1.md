# Лабораторная работа №1
## Знакомство с языком Rocket. Установка и основные конструкции

---

### Цель работы

Научиться собирать компилятор Rocket из исходного кода, запускать программы и писать базовые конструкции языка: переменные, выражения, условия, циклы.

---

### Теоретическая часть

**Rocket** — компилируемый язык программирования со статической типизацией. Исходный код `.rocket` компилируется в байткод, который исполняется собственной стековой виртуальной машиной.

Поддерживаемые примитивные типы:

| Тип | Пример |
|-----|--------|
| `Int` | `42` |
| `Double` | `3.14` |
| `String` | `"hello"` |
| `Bool` | `true`, `false` |

Объявление переменных:
```swift
let x: Int = 10       // изменяемая
const y: Int = 20     // константа
let z = x + y         // тип выводится автоматически
```

### Задание 1. Сборка компилятора

1. Клонируйте репозиторий:
```bash
git clone <url репозитория>
cd MyLanguage
```

2. Соберите проект:
```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

3. Убедитесь, что исполняемый файл создан:
```bash
ls build/MyLanguage
```

### Задание 2. Первая программа

Создайте файл `hello.rocket` со следующим содержимым:

```swift
print("Hello, Rocket!")
```

Запустите:
```bash
./build/MyLanguage hello.rocket
```

Ожидаемый вывод:
```
Hello, Rocket!
```

### Задание 3. Переменные и арифметика

Создайте файл `math.rocket`:

```swift
let a: Int = 10
const b: Int = 20
let c = a + b * 2
print(c)               // 50

let d: Double = 3.14
let e: Double = 2.0
print(d * e)           // 6.28

let s1: String = "Hello, "
let s2: String = "Rocket!"
print(s1 + s2)         // Hello, Rocket!

let flag: Bool = true
print(flag)            // true
```

**Вопросы для отчёта:**
- Чем отличается `let` от `const`?
- Что произойдёт, если попытаться присвоить новое значение константе?

### Задание 4. Условный оператор

Создайте файл `condition.rocket`:

```swift
let score: Int = 75

if (score >= 90) {
    print("Отлично")
} else if (score >= 70) {
    print("Хорошо")
} else if (score >= 50) {
    print("Удовлетворительно")
} else {
    print("Неудовлетворительно")
}
```

Запустите и убедитесь в выводе `Хорошо`.

Измените значение `score` и проверьте остальные ветви.

---

### Задание 5. Цикл while

Создайте файл `loop.rocket`:

```swift
let i: Int = 1
let sum: Int = 0

while (i <= 10) {
    sum = sum + i
    i = i + 1
}

print("Сумма от 1 до 10:")
print(sum)   // 55
```

### Задание 6. Работа с массивами

Создайте файл `array.rocket`:

```swift
let arr = [10, 20, 30, 40, 50]

print("Первый элемент: " + arr[0])
print("Последний элемент: " + arr[4])

arr[2] = 99
print("После замены третьего элемента:")
print(arr)

let j = 0
while (j < 5) {
    print(arr[j])
    j = j + 1
}
```
